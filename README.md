# E-Commerce Backend

A secure and scalable RESTful E-Commerce Backend built using Java and Spring Boot.

## 🚀 Features

- User Registration and Login
- JWT Authentication
- Role-Based Authorization
- Product CRUD Operations
- Product Search, Filtering and Sorting
- Pagination
- Shopping Cart Management
- Order Creation and Checkout
- Order Status Management
- Order Cancellation
- Payment Processing
- Address Management
- Global Exception Handling
- Request Validation
- BCrypt Password Encryption
- JPA Entity Relationships
- Transaction Management
- Logging with SLF4J
- Unit Testing with JUnit and Mockito
- Swagger/OpenAPI Documentation

## 🛠️ Tech Stack

- Java 21
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- Spring Security
- JWT
- MySQL
- Maven
- JUnit
- Mockito
- Swagger / OpenAPI
- Git & GitHub
- Postman
